# Hyper Sand Sandbox

Hyper Sand Sandbox is a browser-based cellular automaton sandbox for sand, water, oil, and fire for now.

## Run Locally

```bash
npm install
npm run dev
```

## Architecture

```text
Canvas UI
   ↓
EngineCore
   ↓
Cellular-automata physics
   ↓
CanvasRenderer
```
